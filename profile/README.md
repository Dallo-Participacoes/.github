## Bem-vindo à Dallo

Este é o espaço de tecnologia e desenvolvimento da **Dallo Participações**. Reunimos software, automações e integrações para aproximar as necessidades do negócio das soluções que chegam às equipes.

Acreditamos em tecnologia útil: processos mais simples, informações conectadas e ferramentas que ajudam as pessoas a trabalhar melhor.

## Nosso ecossistema

| Área | O que buscamos construir |
| :--- | :--- |
| **Aplicações de negócio** | Sistemas e ferramentas para apoiar as operações e a gestão. |
| **Integrações** | Conexões entre aplicações, serviços e fontes de informação. |
| **Automação** | Fluxos que reduzem tarefas manuais e retrabalho. |
| **Dados** | Informações organizadas para análise e apoio à decisão. |

## Colabore com a equipe

Cada projeto é um ponto de encontro entre pessoas, contexto e código. Para começar:

1. **Conheça o projeto.** Leia o README e as orientações disponíveis no repositório.
2. **Converse sobre a melhoria.** Use as issues do projeto para dúvidas, sugestões e relatos de problemas.
3. **Construa em conjunto.** Proponha alterações por pull request, explicando o objetivo e como validar a mudança.

Entre com sua conta vinculada à Dallo para visualizar os projetos aos quais você tem acesso.
